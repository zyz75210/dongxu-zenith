## 一、开工动作

### 1.1 打开项目（每天都一样，2 分钟）

1. 打开 **VS Code**
2. `文件` → `打开文件夹` → 选 `E:\workbuddy任务文件夹\任务一\CalendarApp` → 点「选择文件夹」
3. 按 ``Ctrl + ` `` 打开终端（Esc 下面那个带波浪线的键），或菜单 `终端` → `新建终端`
4. 确认终端提示符是 `PS E:\workbuddy任务文件夹\任务一\CalendarApp>`（不是就重做第 2 步）
5. 输入这一行回车：
   ```
   npx expo start
   ```
6. 等十几秒，出现二维码 → 手机用 **Expo Go** 扫码

**三个最常见的问题**

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 手机卡在「Downloading JavaScript bundle」 | 电脑有 VPN / 虚拟网卡，Expo 选错了网卡 | `Ctrl + C` 停掉，然后跑 `$env:REACT_NATIVE_PACKAGER_HOSTNAME="192.168.10.103"; npx expo start --lan`（IP 用 `ipconfig` 看「WLAN」那段的 IPv4，换网络会变） |
| 提示「禁止运行脚本」 | PowerShell 安全策略 | 先跑 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force`，再重试 |
| `npx` 认不出来 | 环境变量问题 | 改用 `node_modules\.bin\expo.cmd start` |

### 1.2 出一个新安装包（要装到手机、或发给别人测试时）

这台电脑**没有装安卓开发环境**（JDK / Android SDK 都没有），所以走不了本地打包，只能用云构建。项目已经配好，命令固定不变：

**第一步（只做一次）：把 token 放进 `.env.local`**

项目根目录有个 `.env.local` 文件，里面一行：

```
EXPO_TOKEN=
```

用 VS Code 或记事本打开它，在 `=` 后面粘上 Expo 的 token（在 expo.dev → Settings → Access tokens 生成，`ghp_` 开头的是 GitHub 的，别用错），保存。
这个文件已被 git 忽略，永远不会被提交或推到 GitHub。

**第二步（每次出包）：在终端跑这一行**

```
npx eas-cli build -p android --profile preview --non-interactive
```

- 大约 10-20 分钟后终端会给出一个下载链接，末尾是 `.apk`
- 直接把 apk 传到手机上装（微信文件传输助手最省事）
- 构建产物也可以让我下载到 `CalendarApp\build\` 目录

**两个可选参数**

| 想要什么 | 命令里改哪 |
|---|---|
| 包更小（只支持 64 位新手机） | 把 `--profile preview` 改成 `--profile preview-lite` |
| 上架商店用的 aab | 把 `--profile preview` 改成 `--profile production` |

> 注意：EAS 免费额度按自然月计算。如果提示超限，就等月初，或者升级计划。

**第三步：装机后先看这三点**

1. 打开 App 不闪退、首页能出来
2. 底部五个 tab 都能点
3. 新建一条日程能保存、杀掉进程重开还在

## 三、待你拍板的设计项（7 条，按性价比排序）

这七条都是**我发现了但没敢动**的，因为都属于视觉或体验取舍，得你定。每条我都写了「现在什么样」「可以怎么改」「改动多大」。

### ⬜ 1. 「去训练 ›」是假入口 —— 上架前必须处理

**现在**：每条日程卡上都有一个蓝色「去训练 ›」，点了只弹一句「训练板块还在装修，先记着这条」。一天排四条就是四个假链接。

更别扭的是：**已经勾选完成的日程，下面照样写着「去训练」**——练完了还让你去练一次。

**可以怎么改**：
- A. 全删掉（最干净，等训练页真接上了再放回来）
- B. 只在「今天 + 未完成」的卡上留（有点用，但要写判断）
- C. 改成跳训练页（但训练页现在还不能带参数进入，得先做那部分）

**改动量**：A 十分钟；B 半小时；C 要一天以上。

---

### ⬜ 2. 月历下方空档随月份跳变

**现在**：月历容器高度固定 6 行，但很多月份只有 5 行、2 月可能只有 4 行。多出来的行是空白，于是月历和数据条之间的距离会变：

| 月份行数 | 月历下方空档 |
|---|---|
| 6 行 | 8px |
| 5 行（大多数月份） | 62px |
| 4 行（如 2027 年 2 月） | 116px |

固定高度的好处是切月时数据条不动（不会上下跳）。

**可以怎么改**：
- A. 保持现状（"呼吸感"，但 4 行的月份会显得空）
- B. 容器高度跟随当月行数（切月时会跳 54px，需要配一段过渡动画）
- C. 折中：只跟随「最多 5 行」，6 行的月份允许轻微裁切（不推荐）

**改动量**：B 约两小时，且有碰动画的风险。

---

### ⬜ 3. 今天「时间过了还没勾」和「晚上还没到」长得一样

**现在**：历史日期没勾会显示红色叉（已超时），但**今天**没有这个区分。下午三点看早上九点那条没勾的训练，胶囊还是浅灰空心圆，和晚上八点那条视觉上一模一样。

**可以怎么改**：今天且结束时间已过 → 胶囊换成中性的「已过时」（灰蓝，不用红色，红色留给历史）。

**改动量**：一小时左右，只动胶囊组件。

---

### ⬜ 4. 勾完之后，胶囊从「跳绳」变成「已完成」，类型看不见了

**现在**：完成态胶囊的文字被「已完成」整块替换，卡片上只剩左侧 9px 小圆点的颜色能区分类型。色弱用户勾完就分不清这是哪类训练。

**可以怎么改**：`已完成 · 跳绳` 或 `跳绳 ✓`（保留类型 + 完成标记）。

**改动量**：半小时，但胶囊会变宽一点。

---

### ⬜ 5. 长按某天新建，是个纯隐藏手势

**现在**：在月历上长按某天（0.5 秒）直接以那天新建——很好用，但**没有任何提示**，新用户永远发现不了。这跟你定过的「界面要能自己说话、隐藏手势不算」有点矛盾（长按删除当初就是因此撤掉的）。

**可以怎么改**：
- A. 空状态卡第二行加一句极轻的提示（「长按日期可以直接加一条」）
- B. 只在第一次打开时提示一次
- C. 不提示，保持隐藏（老用户效率高，新用户学不到）

**改动量**：A/B 都只要半小时。

---

### ⬜ 6. 数据条左右两个数字没有主次

**现在**：左边「已坚持 12 天」是 22px 粗体，右边「本周 4/7」是 18px 粗体 + 主色蓝。两个都在抢"这一屏最重要的数字"。

**可以怎么改**：认定一个主角。我建议连续天数为主（它是长期成绩），本周进度退到 15-16px、不用主色，可点性靠箭头表达。

**改动量**：二十分钟，纯样式。

---

### ⬜ 7. 「本周 4/7」点进去是整月口径

**现在**：首页写「本周 4/7」，点进去的报告页却是「本月完成率」，两个数字对不上——用户会以为自己的数据错了。

**可以怎么改**：
- A. 报告页默认按周看，从首页进来就定位到你点的那一周
- B. 首页那行改成「本月 12/20」，和报告页口径一致（更省事，但周进度就没了）

**改动量**：A 约半天（要改报告页的统计范围）；B 一小时。
