**② 相机计数（核心算法多轮迭代）**
- 双跳法判据分叉：并脚跳 / 换脚跳各自独立逻辑
- 换脚跳：`|liftL − liftR|` 差值单路 zigzag（对镜头平移免疫）
- 并脚跳：`min(liftL, liftR) − hipLift × 0.85`（双足离地 + 扣髋平移）
- zigzag 峰值检测 + 自适应回撤 + 走动检测 + 切后台自动暂停

**③ AI 动作分析（全新 posture.ts）**
- 3D worldLandmarks 判据，9 条（侧身/内八/膝盖/手臂/手位/低头/跳高/抬腿）
- 双跳法 × 8 档速度（50个/分一档，0~400）标准表，阈值随实时速度插值
- 提示胶囊：正常绿「动作 OK」/ 警告琥珀，同问题 8 秒内只提醒一次

**④ 语音播报（全新 audio.ts）**
- 比赛语音（MP3 原声）+ 亲切语音（TTS 3-2-1）双模式，训练页底部切换
- 开头口令 + 结束「停」，退出即静音（会话令牌防残留）

**⑤ 重要修复**

- release 闪退根因：SDK 58 默认开 R8 混淆 → 关闭 `enableMinifyInReleaseBuilds`
- MediaPipe 旋转补丁，画面转正

**⑥ UI 细节**

- 未来空日期加「点加号安排 ›」引导

> 注意：token 一定**不要**贴进聊天或发给我，也不要提交到 GitHub（已被 `.gitignore` 忽略）。

`E:\workbuddy任务文件夹\第三版首页ui优化\.workbuddy\memory\` 里的日期 .md，是你所有决策和踩坑记录，没进 GitHub。如果特别在意，可偶尔复制整个 `.workbuddy\memory` 文件夹到网盘/移动硬盘。

## 附：EAS 签名密钥（keystore）导出步骤

> 当前状态：keystore 由 EAS 云端托管（本地无 credentials.json / .jks），每次构建自动调用，**不会丢**。
> 真正需要导出备份的时机是**准备上架 Google Play 之前**。现在 EAS 已经替你安全保管，可以不用急。

**手动导出（上架前做一次即可）：**

1. 在项目目录终端跑：`npx eas-cli credentials -p android`
2. 用方向键选 `Android` → 回车
3. 选 `Keystore: Manage your Android Keystore` → 回车
4. 选 `Download Keystore`（或类似"导出/下载 keystore"的选项）
5. 按提示把导出的 `.jks` 文件 + 密码，存到云盘/密码管理器

> ⚠️ 导出时会显示 keystore 密码和 alias 密码，**务必截图或记下**，和 .jks 文件放一起。丢了密码 = 文件作废。
