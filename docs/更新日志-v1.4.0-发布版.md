# 跳程 Zenith v1.4.0 更新日志

**发布日期**：2026-11-27
**版本**：v1.4.0

---

### 一、训练闭环打通

从「排日程」到「练完有成绩」整条链路走通了：

- **新建页**：四种训练内容（定时跳 / 定数跳 / 花样跳 / 自由跳），时长改成直观的分/秒滚轮，定数跳可调目标个数
- **详情页**：新增「训练内容·目标」「跳法」信息项，加了训练视频占位卡（下个版本接录制），完成情况右侧加了「▶ 开始训练」按钮
- **成绩页（全新）**：训练记录按月分组（今天/昨天置顶 + 年月归组），右上角搜索可按日期快速查找
- **成绩绑日程**：从日程进训练，完成后自动给那条日程打勾
- **结算页**：训练完成全屏结算，可编辑名称、再跳一次、保存成绩

### 二、相机计数

- **双跳法判据分叉**：并脚跳、换脚跳各自独立的计数逻辑，训练页可切换
- 换脚跳用差值法（对镜头晃动免疫）；并脚跳用「双足离地 + 扣髋平移」判据
- 走动检测、切后台自动暂停

### 三、AI 动作分析（全新）

- 用 3D 姿态识别，9 条判据：侧对镜头 / 脚内八 / 膝盖太弯 / 手臂张太开 / 两手不齐 / 手抬太高 / 手放太低 / 低头看脚 / 跳太高，外加换脚跳专属的「抬腿幅度」
- 并脚跳、换脚跳各一套标准，且**随速度分 8 档**（50个/分一档，0~400），跳得越快标准越严格
- 提示胶囊：正常显示绿色「动作 OK」，出问题变琥珀色提示，同一个问题 8 秒内只提醒一次

### 四、语音播报（全新）

- **比赛语音**（裁判口令 MP3 原声）+ **亲切语音**（3-2-1）双模式，训练页底部一键切换
- 开头口令 + 结束「停」，退出训练立刻静音

### 五、修复

- 修复通知提示音的警告
- 修复 release 包进相机页闪退的问题（SDK 58 代码混淆导致的）
- 修复相机画面横躺的问题，画面转正

### 六、已知问题（后续版本）

- 比赛语音的中间报时（"十/二十/三十"）还没接
- 视频录制、AI 评分还没做
