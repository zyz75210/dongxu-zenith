## 这一版做了什么

**首页日历整个重做了一遍**：从「一个能看日期的日历」变成「打开就知道自己练到哪儿、今天该干什么」。

### 首页

- **训练圆点**：有安排的日期，数字下方亮起小圆点（跳绳绿 / 体能紫 / 跑步蓝 / 休息灰蓝），同类只画一个
- **凸台**：有圆点的日期灰条向下延伸，连续日期连成一整条，中间无白缝、侧边平直
- **周末**：周六周日日期橙色加粗；跨月补位日期淡化；去掉「第 N 周」
- **数据条（新增）**：左侧连续天数 + 火焰，每 10 天升一阶、共 11 阶，颜色变热、尺寸变大、火星变多，每阶配一句文案；右侧「本周 X/Y」可点进报告页
- **状态分三态**：今天 / 历史 / 未来各说各的，不再出现「三个月前的那天，你已坚持 12 天」
- **空状态重做**：三个训练色块 + 「慢走三分钟，也算练过」+ 「先动三分钟」（表单时长预设 3 分钟）
- **列表卡片**：完成态三重信号（删除线 + 转灰 + 蓝色已完成）、标题限长（中文 20 字 / 英文 40 字母）、超限红字提醒
- **首页搜索**：点放大镜输入 `2025.11.25` 跳到那一天，支持 `-` `/` `年月日` 和纯 8 位写法，非法日期当场提示
- **配色统一**：训练三色改马卡龙（奶绿 / 薰衣草 / 奶蓝），灰底统一 `#F2F3F6`，辅助文字压深到 4.4:1 对比度
- **文案全面重写**：去 AI 腔、感叹句改问句、一屏只劝一次

### 新功能

- **重复日程**：每天 / 每周 / 每月，一次排满一年（365 / 53 / 12 次），月底自动夹取，逐天检查时间冲突
- **整串删除**：重复日程删除时可选「删除全部 / 只删这一天 / 取消」
- **删除撤销**：5.2 秒内可撤销，按原位置插回；单条、整串、历史批量都支持

### 内容板块

- 段位地图的分区标题精简为「基础区 / 进阶区 / 高阶区」

### 修复

- 滚到底时右下角加号不再遮住最后一条日程
- 进出搜索、输错日期时日历不再上下跳
- 状态胶囊字号统一，勾选瞬间文字不再轻跳
- 数据条统计跟随选中日期所在的周
- 保存时校验时间先后，重叠给轻提示

### 安装

下载下方 `dongxu-zenith-1.3.0.apk`（arm64 + armv7，安卓 7.0 以上），传到手机点开安装；首次提示「未知来源」时允许即可。
