# 动序ZENITH v1.3.0 更新日志

发布日期：2026-11-24
上一版本：v1.2.0
适用平台：Android / iOS

---

## 一句话概括

这一版把**首页日历整个重做了一遍**：从「一个能看日期的日历」变成「打开就知道自己练到哪儿、今天该干什么」的主界面。同时新增了重复日程、删除撤销、首页搜索三件实用功能。

---

## 一、重点：首页日历重构

### 1. 月历：从「一格格日期」到「一眼看出哪天练过」

**新增训练圆点**
每个有安排的日期，数字下方会亮起小圆点。同一类型只画一个点，顺序固定为 跳绳 → 体能 → 跑步 → 休息。一天排了两类，就是两个点并排。

圆点直径 5px、间距 3px，垂直居中在灰条里，不会偏上或偏下。

**新增「凸台」**
有圆点的那些日期，背后的浅灰长条会向下延伸出一截，把圆点包在里面，形成一个小小的凸台。
关键的细节：**相邻的连续日期会连成一整条**，而不是一个个独立的小方块；中间不会出现白缝；连续段的左右两端做了填平处理，侧边是平直的一条边，不是「( )」那样的凹口。

**周末单独上色**
周六、周日的日期数字用橙色加粗（`#FF9A45`），比工作日更容易定位。选中周末时数字变白，橙色暂时让位——这是有意的，选中态优先级更高。

**跨月补位淡化**
月初前面补上来的上月末尾日期（比如 11 月 1 日前面那几天 10 月的日子）用浅灰淡化，不再和本月日期抢注意力。

**去掉「第 N 周」**
原来每行前面有个周数标签，占宽度又没人看。删掉之后整行日期更舒展。

**选中动画保持原样**
选中日期的蓝色液体滑块（含跨行时的「旧点溶解 + 新点绽放」、数字延后变白）一行代码没动，仍是这个 App 最有辨识度的手感。

### 2. 数据条：全新的一块，回答「我练得怎么样」

原来首页没有这一块。现在它夹在月历和日程列表之间，一行说完两件事：

**左边：连续战绩（今天是重点）**
- 今天已经练了 → 实心火焰 + `已坚持 12 天` + 一句升阶文案
- 今天还没练、但有连续记录 → 线框火焰 + `已坚持 12 天` + `今天补上，别断了`
- 今天没排任何东西 → 只说事实：`今天还没排`（不再劝，劝的话归下面那张空状态卡）
- 今天之前的日子 → 说那天的结果：`全部完成` / `完成 2/3` / `没完成` / `休息到位`
- 今天之后的日子 → 只说安排：`已安排 2 条` / `还没安排`

**火焰：每 10 天升一阶，共 11 阶**
火焰是自绘的（不是 emoji，emoji 是全彩写实风，和扁平的界面不是一套）。每升一阶，颜色更热一档（从浅橙到暗红）、尺寸从 17px 长到 21px、火星最多 5 颗、第 3 阶起出现光晕、内焰常亮。

每阶配一句话，十天一换：

| 天数 | 文案 |
|---|---|
| 火苗点着了 | 0-9 天 |
| 两位数了，稳住 | 10 |
| 二十天，身体开始认这件事 | 20 |
| 一个月，节奏出来了 | 30 |
| 四十天，靠的不只是意志了 | 40 |
| 五十天，走完一半 | 50 |
| 两个月，别人追不上了 | 60 |
| 七十天，稳得不像话 | 70 |
| 八十天，一百在望 | 80 |
| 九十天，就差最后一步 | 90 |
| 一百天，这事儿你拿下了 | 100 |

**右边：本周进度，可以点**
`本周 4/7 ›` —— 4 是已完成，7 是本周排了几条训练（休息日不算）。点它进数据报告页。
- 这周完全没有训练 → 变成可点的 `排一条 ›`，点开直接以选中日期新建
- 这周只排了休息 → `本周休息 3 天`（纯文字，不能点）
- 全新用户（一条记录都没有）→ `想安排运动就点我 ›`

**统计口径**
「本周」跟着你选中的日期走：翻到上周，它就说「当周」，数字也是上周的。

### 3. 当天日程列表：信息层级重排

**标题行**

```
11月24日 星期二   先点开看详情 · 点标签标完成
1 个日程
```

日期 + 一句操作提示在同一行（提示常驻，不再只给新用户看），数量单独一行放下面。原来右上角那个「全部」删掉了——设置页和「我的」页都有历史日程入口，它只快一步，却一直占着标题行最值钱的位置。

**日程卡片**
左侧一个小圆点标类型（颜色和日历上的圆点一致），中间标题 + 时间，右侧状态胶囊。

**状态胶囊**
四种状态，靠底色 + 图标 + 字重区分，不靠字号：

| 状态 | 样子 |
|---|---|
| 未完成 | 浅灰底 + 空心圆 + 类型名（空心圆暗示「点一下能勾上」） |
| 已完成 | 浅蓝底 + 勾 + `已完成` |
| 已超时 | 浅红底 + 叉 + 类型名（今天之前没勾的） |
| 休息日 | 浅灰蓝底 + `休息日`，不显示勾选圈（休息不需要你操作） |

点胶囊就切换完成状态，伴随一次「弹一下」的缩放和一次重力震动。

**完成态三重信号**
标题加删除线 + 标题转灰 + 胶囊变蓝，三个信号同时出现，扫一眼就知道哪条完成了。

**标题限长**
中文 20 字、英文 40 字母（按视觉宽度算，一个汉字约等于两个字母）。超了会在输入框下面红字提醒，但不会偷偷改你写的内容。

### 4. 空状态：新用户唯一的落点

一天什么都没排时，下方不是一句干巴巴的「暂无日程」，而是：

```
● 跳绳    ● 体能    ● 跑步

慢走三分钟，也算练过
不用装备，不用热身，想停就停

[ + 先动三分钟 ]
```

三个色块先告诉你「这是个练什么的 App」，再给一个门槛极低的动作（三分钟，按钮点开后表单时长就是预设的 3 分钟，不是默认的 90 分钟）。

选中的不是今天时，文案会变：过去的日期说「这天没留下记录」，未来的日期说「这天还是空的」，按钮统一是「排一条」。

**右下角加号**只在当天有日程时才出现。空状态时卡片里已经有一个蓝色主按钮了，再放一个圆钮，两个蓝色抢同一件事。

### 5. 顶部：搜索来了

**点右上角放大镜**，整条头部换成输入框（头像和月份暂时让位，页面不会被多挤一行），键盘自动弹出，灰字提示 `例如 2025.11.25`。

- 认得的写法：`2025.11.25`、`2025-11-25`、`2025/11/25`、`2025年11月25日`、`20251125`
- 输入合法后右侧「跳转」才从灰变蓝
- 输错的日期（`2025.2.30`、`2025.13.1`、`2025.2.29` 这种不存在的）当场红字提示，改字即清
- 跳转后，如果目标在同一个月，选中的蓝圆会滑过去；在别的月份就整块换页——和点日期、点「回到今天」完全同一条路径

**进出搜索带转场**：起雾 150ms、对焦 260ms，比切 tab 略长一点，屏幕不压暗，只有一层很轻的模糊。

### 6. 配色与灰阶：统一到三档

原来页面上的近白色有四种（白底、#F7F8FA、#F2F3F6、#EEF0F4），层级其实只有「底、块、线」三层。这一版：

- 所有灰底统一到 **#F2F3F6**（日历长条、凸台、数据条共用）
- 辅助小字从 #9299A6 压深到 **#767E8C**（白底对比度 2.8:1 → 4.4:1）
- 三个训练色改**马卡龙**：跳绳 `#79D3A6` 奶绿、体能 `#C0AEFB` 薰衣草、跑步 `#86B8FF` 奶蓝；休息 `#9DB4C0` 柔灰蓝。原来的草绿和浓蓝偏沉

### 7. 文案语气全面重写

- 去掉「哦」「啦」这类 AI 腔
- 感叹句改问句：「第一次来？」而不是「欢迎使用！」
- 降低门槛：「慢走三分钟，也算练过」比「跳三分钟」更容易点头
- 一屏只劝一次：数据条只说事实，劝的活归空状态卡
- 新用户 / 回归用户分开说：一条记录都没有才是「第一次来？」，不是「好久不见」

## 二、新功能

### 1. 重复日程

添加日程页的时间行下面多了一行「重复」：**不重复 / 每天 / 每周 / 每月**。

选重复后，会一次性排满**接下来一年**：

| 频率 | 一年内排几次 |
|---|---|
| 每天 | 365 次 |
| 每周 | 53 次 |
| 每月 | 12 次 |

- 保存按钮上会提前写好：`保存日程 · 一年内 53 次`，点之前就知道会排几条
- 保存后提示：`每周一次，已排好 53 次`
- 月底会夹取：1 月 31 日选「每月」，2 月落到 28 日（闰年 29 日），不会滚到 3 月 3 日
- 编辑某一条只改那一天，不影响其他实例
- 时间冲突会逐天检查：「有 3 天和已有日程时间重叠」会明确告诉你几天

### 2. 重复日程的删除要问清楚

详情页信息卡会多一行「重复 · 每天 · 一年内」，让人在删之前就知道这是一组。点删除时弹三个选择：

- **删除全部** —— 整串一起清
- **只删这一天** —— 只删当前这条
- **取消**

### 3. 删除可以撤销

删完（单条 / 整串 / 历史页批量）后底部会出现一条提示，停留 **5.2 秒**：

```
已删除 53 条重复日程  │  撤销
```

点「撤销」立刻恢复，而且是**按原位置插回**，不是你重新排到列表末尾。

| 问题 | 现在 |

| 滚到底时，右下角加号挡住最后一条日程的状态胶囊 | 列表底部留白加大，加号不再遮内容 |

## 五、已知问题 / 未完成

这些是明确知道、但这一版没有做的，不是 bug：

1. **周视图吸顶没做**。做过一版（上滑时月历收成一周），效果不理想，已回退。后续重做时不用重新踩坑：不能用「固定月历 + 独立列表」两区结构（会变成双倍速滚动），正解是绝对定位覆盖层 + 单个滚动容器。
2. **「去训练 ›」还是假入口**。每条日程卡上都有，点了只弹一句「训练板块还在装修」。一天四条就是四个假链接。
3. **报告页口径不一致**。首页写「本周 4/7」，点进去的报告页是按整月算的，两个数字对不上。
4. **「我的」页的连续天数没跟火焰同色**。功能正常，只是没接入新的阶位色。
5. **积累页的卡片、编辑、更多全部未接**，点了只给提示。
6. **「下滑开始安排运动吧」已退役**。空周时页面常常不足一屏，其实滑不动，换成了可点的「排一条 ›」。
