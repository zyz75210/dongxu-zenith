# 怎么出安卓安装包（最简版）

> 先说一句最重要的：**如果你只是想看效果、改完想立刻看到，不需要出安装包**。
> 手机装个 Expo Go，电脑跑 `npx expo start`，扫码就能看，改完自动刷新。
> **只有这几种情况才需要出包**：要装到没装 Expo Go 的手机上、要发给别人试、要上架。

---

## 一、为什么需要 token

这台电脑没装安卓开发环境（JDK、Android SDK 都没有），所以打不了本地包，只能用 Expo 的**云端打包机**。

云端不认识你，所以需要一把"钥匙"——就是 token。它不是你账号的密码，是一串可以在 expo.dev 后台随时生成、随时作废的临时凭证。

**你手上那两串 token 就是干这个的。**（如果其中一串是 `ghp_` 开头，那是 GitHub 的，这里用不上，留着推代码。）

---

## 二、两种做法，选一个

| | 做法 A：你把 token 发我 | 做法 B：你自己双击一个文件 |
|---|---|---|
| 你要做几步 | **1 步**（把 token 发我） | 4 步（填文件、双击、等、发我链接） |
| 谁来做 | 我全做 | 你点一下，我等结果 |
| 适合 | 现在就要包、不想折腾 | 以后想自己随时出包 |
| 安全 | token 会留在聊天记录里，用完你可以去后台作废重发 | token 只在你电脑的本地文件里，不经过聊天 |

**今晚建议用 A。** 以后熟悉了再用 B。

---

## 三、做法 A：你把 token 发我（1 步）

1. 打开 expo.dev 后台（浏览器）→ 右上角头像 → **Account settings** → **Access tokens**
2. 复制那串 token（或者用你手上已经有的那串）
3. 直接粘到对话里发我，说一句「用它出包」

我拿到后会做这些，你不用管：

- 写进本地的 `.env.local`（这个文件不会上传 GitHub）
- 验证 token 属于账号 `zyzok`
- 启动云构建，等 10-20 分钟
- 把 apk 下载到 `E:\workbuddy任务文件夹\任务一\CalendarApp\build\`，告诉你文件名

> 构建完建议你去 expo.dev 把那串 token 作废、重新生成一串（点 Revoke），这样聊天记录里那串就失效了。

---

## 四、做法 B：双击一个文件（4 步）

我已经给你写好了一个脚本，叫 **`出安卓包.cmd`**，就在项目文件夹里。

**第 1 步：把 token 填进 `.env.local`**

1. 在 VS Code 左侧文件列表里找到 `.env.local`（如果没有，看第 5 节"常见问题"）
2. 点开它，你会看到一行：
   ```
   EXPO_TOKEN=
   ```
3. 在 `=` 后面粘上 token，变成：
   ```
   EXPO_TOKEN=你复制的那串
   ```
4. 按 `Ctrl + S` 保存

**注意**：不要加引号、不要加空格、不要分成两行。

**第 2 步：双击 `出安卓包.cmd`**

在文件管理器里打开 `E:\workbuddy任务文件夹\任务一\CalendarApp`，找到 `出安卓包.cmd`，**双击**。

会弹出一个黑窗口，出现这些字就说明在正常跑：

```
============================================
 Zenith  -  Android APK builder
============================================

[1/2] Checking token ...
zyzok
[2/2] Building APK. About 10-20 minutes. Keep this window open.
```

**第 3 步：等，别关窗口**

10-20 分钟。窗口里会刷很多行，看不懂没关系，只要最后出现：

```
[OK] Build finished. The .apk download link is printed above.
```

**第 4 步：把链接发我**

往上翻，找到一行 `https://expo.dev/artifacts/....apk` 的链接，复制发我。我会把它下载到 `build\` 目录，并告诉你文件名和大小。

## 五、常见报错对照

双击脚本后如果没跑起来，对着这个表看：

| 窗口里显示 | 意思 | 怎么解决 |
|---|---|---|
| `[X] .env.local not found in this folder` | 文件不在这 | 确认你双击的是 `CalendarApp` 文件夹里的脚本，不是别处的 |
| `[X] EXPO_TOKEN is empty in .env.local` | token 没填进去 | 重新打开 `.env.local`，确认 `=` 后面有内容并保存 |
| `[X] Token invalid or expired.` | token 不对或过期了 | 去 expo.dev 重新生成一串 |
| `EAS build quota exceeded` | 这个月的免费次数用完了 | 等月初，或换一个 Expo 账号 |
| 窗口一闪就消失 | 双击太快看不到错 | 右键脚本 → 重命名不改 → 右键 → 在终端中运行；或者直接告诉我，我来看 |
| 一直停在 `Checking token` 不动 | 网络连不上 expo | 检查网络 / 关掉 VPN 再试 |

## 六、包出来了，怎么装到手机

1. 我下载好的文件在 `E:\workbuddy任务文件夹\任务一\CalendarApp\build\`，名字类似 `zenith-1.3.0.apk`
2. 传到手机：**微信文件传输助手**最省事（电脑微信发给自己，手机微信收）
3. 手机上点开那个 apk 文件
4. 第一次会提示"不允许安装未知来源应用" → 点**设置** → 允许这个应用（微信/文件管理器）安装 → 返回继续
5. 安装完，桌面出现「动序ZENITH」

**装完先看三件事**：能打开不闪退、底部五个 tab 都能点、新建一条日程能保存、杀掉进程重开还在。

## 八、还有一条更省事的路（提前说）

如果你只是想给别人看看界面，不想装机，还有第三条路：
把 `npx expo start` 跑起来，用 **Tunnel 模式**（`npx expo start --tunnel`），会生成一个公网链接，别人用浏览器/Expo Go 打开就能看，不用装包。

**但它不是安装包**，不能上架、不能离线用。真要给别人装，还是得走上面那两条。
