# 换新任务怎么办（零基础版）

> 这份文档只解决一件事：**你在 WorkBuddy 里开了一个新任务，怎么让我重新"记得"这个项目的所有事。**
>
> 看完你应该能：不靠记忆、不靠翻聊天记录，只靠复制粘贴几段话，就让我回到和现在一样的状态。

---

## 第 0 步：先问自己 —— 真的需要新开吗？

**大多数情况下不需要。** 你现在这个对话里的东西（改过什么、为什么这么改、你否决过什么）全都还在，直接接着说话就行，比新开稳得多。

**才需要新开的三种情况**：

1. 这个对话太长、卡顿、或者我明显开始"忘事"
2. 你想换一个完全不同的主题（比如从"改首页"跳到"做一件新功能"），不想混在一起
3. 电脑重启后，你在左侧任务列表里找不到这个对话了

> 如果只是想看进度、问个问题，**不用新开**，直接问。

---

## 第 1 步：新开任务，选对"文件夹"（这一步最关键）

WorkBuddy 开新任务时，有的版本会让你选一个**工作目录 / 文件夹**，有的版本直接用默认目录。

### 如果它让你选文件夹

你有两个都正确的选择，但**效果不同**：

| 你选的文件夹 | 我会自动读到什么 | 评价 |
|---|---|---|
| `E:\workbuddy任务文件夹\第三版首页ui优化` | **会自动带上我的项目记忆**（每天的改动记录、你的意见、踩过的坑） | ✅ 最省事，推荐 |
| `E:\workbuddy任务文件夹\任务一\CalendarApp` | 会读到**代码**，但**读不到记忆**（记忆是按文件夹存的） | 也可以，但要多贴一行路径给我 |

**两个都行，别选其它文件夹。** 选错也不致命，第 2 步的开场白会把路径写死，我能自己找过来。

### 如果它没让你选

那就不用管，直接进第 2 步。开场白里我会先自报"我现在在哪个目录"，你一看就知道有没有选对。

---

## 第 2 步：第一句话，粘贴开场白

**不要先问"你还记得吗"**——新任务里我确实不记得，问了也是白问。直接把下面整块粘进去。

### 版本 A：完整版（换目录、或隔了几天，用这个）

```
【项目】动序ZENITH（跳绳日历 App）
【代码】E:\workbuddy任务文件夹\任务一\CalendarApp（分支 v1.3，当前版本 1.3.0）
【记忆】E:\workbuddy任务文件夹\第三版首页ui优化\.workbuddy\memory\2026-11-24.md
【文档】E:\workbuddy任务文件夹\任务一\CalendarApp\docs\ 下的全部文档

请你先做三件事，做完再回话：
1. 执行 pwd，告诉我你当前的工作目录是什么
2. 读上面【记忆】和【文档】两处，用 5 行以内复述：v1.3.0 改了什么、还没做什么
3. 告诉我你读到了哪些红线

红线（不确认就动 = 犯错）：
- 底部导航栏：结构/图标/文案/顺序/样式/状态色/点击行为，一律不动
- 每个页面右上角的圆钮：只服务本页，页面之间不互通
- 已有动画：月历液体滑块、跨行残影、底部导航小球、勾选震动、长按新建 400ms —— 不删不改不替换
- 数据存储 key 与结构（zenith.* 系列）不改

规矩：每批改动后跑 npx tsc --noEmit；每批汇报"已有动画是否全部保留"。

【今天要做】<在这里写一句话，例如：把「去训练」假入口删掉>
```

### 版本 B：极简版（只是问个问题，不改代码）

```
项目在 E:\workbuddy任务文件夹\任务一\CalendarApp，先读 docs\ 下的文档和
E:\workbuddy任务文件夹\第三版首页ui优化\.workbuddy\memory\2026-11-24.md，
然后回答我：<你的问题>
```

---

## 第 3 步：验证我"真的接上了"（30 秒，别跳过）

粘完开场白，我会回一段话。你要检查三件事：

| 检查什么 | 合格的样子 | 不合格的样子 |
|---|---|---|
| **目录对不对** | 我报出的 `pwd` 是 `E:\workbuddy任务文件夹\...` 开头 | 我说的是别的盘、别的文件夹 |
| **记忆读没读到** | 我能说出具体的东西，比如「v1.3.0 把首页数据条做成火焰 + 本周进度」「重复日程排满一年」 | 我只能说「这是一个跳绳日历 App」这种读过 README 就能说的话 |
| **红线记没记住** | 我能复述四条红线 | 我说「好的，我会注意的」但没说出具体内容 |

**三条全过，就可以开始干活。**

---

## 第 4 步：如果我没接上，怎么补救（按症状对号）

| 症状 | 原因 | 你直接发这句 |
|---|---|---|
| 我说「找不到这个文件 / 路径不存在」 | 路径打错了，或者盘符变了 | `项目在 E:\workbuddy任务文件夹\任务一\CalendarApp，用 ls 确认一下能不能进` |
| 我只说空话，说不出具体改动 | 记忆文件没读到 | `读 E:\workbuddy任务文件夹\第三版首页ui优化\.workbuddy\memory\ 目录下最新的那个 .md，读完复述给我` |
| 我一上来就开始改代码 | 没等确认就动手 | `停。先别改。先把 pwd、你读到的改动、四条红线复述一遍` |
| 我说的东西和昨天不一样 | 我读了旧文档或猜的 | `以 2026-11-24.md 为准，别用 README 里的旧描述` |

**万能兜底一句**：

```
先别动代码。你现在在哪个目录、读到了哪些文件、v1.3.0 改了什么、红线是什么，四个都说一遍。
```

**如果我已经动手改了不该改的东西**（底部导航、右上角按钮、动画），立刻发这句，我会停手并回退：

```
停。你动到底部导航 / 右上角按钮 / 已有动画了，先回退，把改动范围说清楚再继续。
```

这条比任何提醒都有效——因为红线是**你自己说过的话**，不是我猜的偏好。

## 第 5 步：一次新开的完整示范（照这个抄）

**你发**（版本 A，最后一行写今天要做的）：

```
【项目】动序ZENITH ……（整段开场白）
【今天要做】把「去训练」这个假入口删掉
```

**我应该回**（大意）：

> 当前目录 `E:\workbuddy任务文件夹\第三版首页ui优化`。
> 读完记忆和文档，v1.3.0 主要做了：首页数据条（火焰 11 阶 + 本周进度）、月历训练圆点与凸台、列表状态胶囊、空状态、首页搜索、重复日程（一年）、删除撤销、段位地图分区标题精简。
> 还没做：去训练假入口、周视图吸顶（已回退）、报告页按周口径、今天已过时态、无障碍标签等。
> 红线四条：底部导航不动、右上角圆钮只服务本页、已有动画不删不改、数据 key 不改。
> 现在开始做「去训练」：先确认你要 A（全删）还是 B（只留今天未完成的卡）？

**你看到这段话，就说明接上了。** 如果对不上，用第 4 步的表对号。

---

## 第 6 步：五件千万别做的事

| 别做 | 为什么 | 换成什么 |
|---|---|---|
| **同时开两个都在改代码的任务** | 两个会话改同一份文件，后保存的会把前面的覆盖掉，而且 git 里看不出来是谁覆盖的 | 同一时间只留一个"能改代码"的任务；另一个想开就明确说「只读，不许改文件」 |
| **在新任务里说「重新做一遍首页」** | 我会从头再来，把你已经认可的细节全部推翻 | 说具体的那一处：「数据条右边的文字改成 X」 |
| **删掉 `.workbuddy` 文件夹** | 那是项目记忆和会话数据，删了我就真什么都不记得了 | 不用管它，它不占地方也不影响运行 |
| **自己跑 `git checkout` / `git reset` / `git clean`** | 未提交的改动会**直接消失**，且无法恢复 | 要回退跟我说，我用 `git revert`，历史留着、能查、能再退回来 |
| **把 token 直接贴在聊天里** | 会留在会话记录里 | 写进 `.env.local`（这个文件永远不会被提交） |
