# 跳程 Zenith v1.4.0

训练闭环 + AI 动作分析 + 语音播报，跳绳日历从「排日程」打通到「练完有成绩」。

## 这一版做了什么

- **训练闭环**：新建四种训练内容 → 详情页开始训练 → 相机实时计数 → 全屏结算 → 成绩按月归档可搜索，日程自动打勾
- **AI 动作分析**：3D 姿态识别，9+ 条判据（侧身/内八/膝盖/手臂/手位/低头/跳高/抬腿），并脚跳、换脚跳各一套、随速度分 8 档标准
- **语音播报**：比赛语音（裁判口令原声）+ 亲切语音（3-2-1）双模式切换，开头口令 + 结束"停"
- **双跳法计数**：并脚跳 / 换脚跳独立判据，抗镜头晃动

## 安装

- 安卓 APK（内部测试版）：见本 Release 附件 / EAS 构建产物
- 需要相机权限（姿态识别）
