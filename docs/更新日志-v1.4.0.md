- **成绩页（WorkoutListScreen，全新）**：训练记录按月分组（今天/昨天置顶 + 「YYYY年M月」归组），右上角搜索按钮按日期（月/日）筛选本页记录

## 二、相机计数（核心算法多轮迭代）

- **双跳法判据分叉**：并脚跳 / 换脚跳各自独立的计数逻辑（训练页可切换跳法）
- 换脚跳信号最终落定为 **`|liftL − liftR|` 差值单路 zigzag**（对镜头整体平移天然免疫）
- 并脚跳信号 **`min(liftL, liftR) − hipLift × 0.85`**（双足离地 + 扣髋部平移）
- zigzag 峰值检测 + 自适应回撤 + 快节奏放松阈值 + 走动检测 + 切后台自动暂停

## 三、AI 动作分析（posture.ts，全新）

- 用 `worldLandmarks`（3D 米制坐标）判断，解决二维投影看不到屈膝/内八的问题
- 9 条判据：侧对镜头 / 脚内八 / 膝盖太弯 / 手臂张太开 / 两手不齐 / 手抬太高 / 手放太低 / 低头看脚 / 跳太高（+ 换脚跳专属「抬腿幅度」上下双阈值）
- **双跳法 × 8 档速度（50个/分一档，0~400）标准表**，阈值随「当下绝对速度」线性插值，慢速用慢速标准、高速只提醒核心问题
- 标准表文档：`docs/动作评判标准表.md`
- 提示胶囊：节奏卡上方居中，正常绿「动作 OK」/ 警告琥珀，同一问题 8 秒内只提醒一次
