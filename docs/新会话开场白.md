# 新开会话怎么接上（交接说明）

> 背景：我（AI）不跨会话记事。能被「记住」的东西全在磁盘上，新开任务时**要靠你把那几处指给我**，我才能接上昨天的手感、红线和你已经拍过的决定。

---

## 一、为什么会有这个问题

我的工作记忆存在两个地方，都跟「你在哪个目录里开任务」有关：

| 记忆位置 | 内容 | 什么时候会读到 |
|---|---|---|
| `E:\workbuddy任务文件夹\第三版首页ui优化\.workbuddy\memory\2026-11-24.md` | 昨天每一批改动的结论、踩过的坑、你说过的话 | **只有新任务的目录正好是 `第三版首页ui优化`** 时才会自动带上 |
| `E:\workbuddy任务文件夹\任务一\CalendarApp\docs\` | 更新日志 / 测试清单 / 下次开工清单 | 不会自动读，要我主动打开 |

所以：**换目录开任务 = 我什么都不记得**，只有代码是真的。

---

## 二、三种情况，三种做法

### 情况 A：新任务还是在 `第三版首页ui优化` 目录里开

最省事。直接说一句：

```
继续动序ZENITH 首页的优化，先看看你的项目记忆
```

我会自己读 `.workbuddy/memory/` 里最近的记录，然后把当前状态复述给你确认。

### 情况 B：新任务开在 `CalendarApp` 目录里（很多人会这么开，因为代码在这）

我会读到代码，但读不到记忆。请说：

```
读一下 E:\workbuddy任务文件夹\第三版首页ui优化\.workbuddy\memory\2026-11-24.md
和 E:\workbuddy任务文件夹\任务一\CalendarApp\docs\ 下的三份文档，然后告诉我当前状态
```

### 情况 C：新任务开在任意其它目录

同上，也是把这两处路径丢给我。如果连代码路径都不在默认位置，一并给出：

```
项目代码在 E:\workbuddy任务文件夹\任务一\CalendarApp
```

---

## 三、最稳的办法：每次新会话，先贴这一段

复制下面整块（包括分隔线内的所有内容），粘到新任务的第一个输入框里，**只改最后一行**：

```
---
【项目】动序ZENITH（跳绳日历 App）
【代码】E:\workbuddy任务文件夹\任务一\CalendarApp（分支 v1.3，当前版本 1.3.0）
【上下文】请先读这两处，再回话：
  1) E:\workbuddy任务文件夹\第三版首页ui优化\.workbuddy\memory\2026-11-24.md
  2) E:\workbuddy任务文件夹\任务一\CalendarApp\docs\ 下的三份文档
【红线，动之前必须问我】
  - 底部导航栏：结构/图标/文案/顺序/样式/状态色/点击行为，一律不动
  - 每个页面右上角的圆钮：只服务本页，页面之间不互通
  - 已有动画：月历液体滑块、跨行残影、底部导航小球、勾选震动、长按新建 400ms —— 不删不改不替换
  - 数据存储 key 与结构（zenith.* 系列）不改，否则老用户数据丢失
【规矩】
  - 每批改动后跑 npx tsc --noEmit，能打包就打包验证
  - 每批汇报一句「已有动画是否全部保留」
  - 我看不到真机渲染，纯视觉的事先描述清楚再动手
【今天要做】<在这里写一句话>
---

如果我不确定，先回一句「已读懂上下文」并复述当前状态给我确认，别直接改代码。
```

最后可以拆成三块，一行只写一句，例如：

- `【今天要做】把「去训练」这个假入口删掉（下次开工清单第 1 条）`
- `【今天要做】做一个按周看的报告页`
- `【今天要做】先带我把测试清单 A 组过一遍，我边点你边记问题`

---

## 四、如果新会话里我只顾着改代码、忘了红线

直接把这句发给我，我会立刻停：

```
停。你动到底部导航 / 右上角按钮 / 已有动画了，先回退，把改动范围说清楚。
```

这条比任何提醒都有效——因为红线是**你说过的话**，不是我猜的偏好。

---

## 五、还有一种「新开任务」：你只是想看进度，不想改代码

那更简单，问这三句里的任意一句就够：

- 「这个项目现在是什么状态？」
- 「v1.3.0 之后还有哪些没做？」
- 「把测试清单里我没勾的项列出来」

我会去读 `docs/` 下那三份文档回答，不会乱动代码。
